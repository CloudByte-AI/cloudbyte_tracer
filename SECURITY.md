# Security

Never include agent/provider keys, prompts or customer content in public issues. Use private vulnerability reporting on CloudByte-AI/cloudbyte_tracer once the repository exists; until then contact your CloudByte engineering maintainer internally.

Rotate exposed keys in CloudByte. Diagnostics omit payloads and credentials. The initial 0.1.0 has no long-term support policy; maintainers must document supported versions before publication.
